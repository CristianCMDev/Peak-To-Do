**Peak To Do** es una aplicación de tareas simple y moderna desarrollada con **Ionic 7 + Angular 20**.  
Permite crear, editar y eliminar tareas, organizar categorías y marcar tareas como completadas, con todo persistido en **LocalStorage**.

---

## 🚀 Características

- Crear tareas con nombre, descripción y categoría.
- Editar tareas directamente desde la pantalla de detalle.
- Categorías personalizables.
- Marcar tareas como completadas con checkbox.
- Guardado automático en **LocalStorage**.
- Interfaz responsiva para dispositivos móviles.

---

## 🛠 Tecnologías

- **Ionic 7**
- **Angular 20**
- **TypeScript**
- **LocalStorage** para persistencia de datos
- **UUID** para generar identificadores únicos de tareas
- **Ionicons** para iconos

## 💾 Instalación

1. **Clona el repositorio:**

```bash
git clone https://github.com/CristianCMDev/peak-to-do.git
cd peak-to-do

2. Instala dependencias:

npm install

3. Instala Ionic CLI globalmente (si no lo tienes):

npm install -g @ionic/cli

4. Ejecuta la aplicación en modo desarrollo:

ionic serve
La app se abrirá en tu navegador en http://localhost:8100.
